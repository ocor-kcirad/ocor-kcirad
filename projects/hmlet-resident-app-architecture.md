## 🏗️ Project Spotlight: Resident App (Hmlet Pte. Ltd.)
> **Role:** Android Engineer (Remote - Singapore) | Jan. 2019 – Apr. 2021

### 📌 The Challenge
The original codebase was a legacy **Java** system with high technical debt and a tightly coupled architecture. As the resident base grew, the platform required a modern, scalable foundation to support rapid feature deployment and reduce manual errors during the release cycle

### 🛠️ The Solution: Modernization & Automation
Spearheaded a complete architectural overhaul, transforming the app into a reactive, maintainable mobile solution:

* **Language Migration:** Successfully migrated the core codebase from **Java to Kotlin**, improving null safety and code conciseness.
* **Architectural Overhaul:** Implemented **MVVM (Model-View-ViewModel)** and **Clean Architecture** principles to decouple business logic from the UI.
* **CI/CD Leadership:** Engineered a robust **Continuous Integration (CI) pipeline**, automating builds, unit tests, and deployments to reduce manual intervention.
* **Internal Tooling:** Designed and built a specialized internal communication tool for community managers to streamline resident interactions.

### 📈 Key Results
* **Scalability:** The new Clean Architecture allowed for independent feature scaling and easier onboarding of new developers.
* **Velocity:** Automated CI/CD significantly accelerated the development lifecycle, allowing the team to focus on high-impact features rather than deployment logistics.
* **Quality:** Transitioning to Kotlin and implementing MVVM led to a more testable and stable application.

### 🧰 Technical Stack
* **Languages:** Kotlin, Java
* **Architecture:** MVVM, Clean Architecture, SOLID Principles
* **Asynchronous:** RxJava, Coroutines
* **DevOps:** CI/CD Pipelines, Gradle, Git
